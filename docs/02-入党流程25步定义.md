# 发展党员工作流程 — 5 阶段 25 步定义

> 依据《中国共产党发展党员工作流程图》（中央组织部组织一局编）
> 本文档是 `dev_stage` / `dev_step` 两张表的**种子数据来源**，与代码中的规则策略类一一对应。

## 图例

- **办理角色** — 有权办理该步骤的角色（可多个）
- **期限** — 时间约束，对应规则策略
- **材料** — 该步骤必须上传/生成的档案材料
- **规则** — 绑定的 `rule_key`（见《01-系统设计.md》5.4）

## 阶段一：申请入党

### STEP_01 递交入党申请书

| 项 | 内容 |
|---|---|
| 办理角色 | 入党申请人本人 |
| 期限 | — |
| 材料 | 入党申请书（**书面**，本人提出） |
| 规则 | `QUALIFICATION_RULE`：年满 18 周岁的中国公民；承认党的纲领和章程；愿意参加党的一个组织并在其中积极工作；愿意执行党的决议；按期交纳党费 |
| 说明 | 向工作、学习所在单位党组织提出；没有工作、学习单位或单位未建党组织的，向居住地党组织提出；流动人员还可向单位所在地或单位主管部门党组织、流动党员党组织提出 |

### STEP_02 党组织派人谈话

| 项 | 内容 |
|---|---|
| 办理角色 | 支部书记 / 副书记 / 组织委员 |
| 期限 | **收到入党申请书后 1 个月内** → `DEADLINE_RULE(days=30)` |
| 材料 | 谈话记录 |
| 规则 | `DEADLINE_RULE` |
| 说明 | 了解申请人基本情况，介绍入党条件和程序，加强教育引导 |

## 阶段二：入党积极分子的确定和培养教育

### STEP_03 推荐和确定入党积极分子

| 项 | 内容 |
|---|---|
| 办理角色 | 支部委员会 |
| 期限 | — |
| 材料 | 推荐意见、支委会会议记录 |
| 规则 | 须经**支部委员会集体研究决定**；综合运用推荐结果，防止简单以票取人 |
| 说明 | 范围：已递交入党申请书且党组织已派人谈话的人员。方式：党员推荐、群团组织推优等 |

### STEP_04 上级党委备案

| 项 | 内容 |
|---|---|
| 办理角色 | 上级党委 |
| 期限 | — |
| 材料 | 入党申请人基本情况、推荐和推优情况、支部委员会意见 |
| 规则 | `MATERIAL_REQUIRED_RULE` |
| 说明 | 了解入党积极分子是否具备条件；手续是否齐全 |

### STEP_05 指定培养联系人

| 项 | 内容 |
|---|---|
| 办理角色 | 支部委员会 |
| 期限 | — |
| 材料 | 培养联系人登记表 |
| 规则 | `QUALIFICATION_RULE`：数量 **1—2 名正式党员** |
| 说明 | 任务：向入党积极分子介绍党的基本知识；了解其政治觉悟、道德品质、现实表现和家庭情况等，做好培养教育工作，引导其端正入党动机；及时向党支部汇报其情况；向支部提出能否将其列为发展对象的意见 |

### STEP_06 培养教育考察 ⭐周期性

| 项 | 内容 |
|---|---|
| 办理角色 | 培养联系人 / 党支部 |
| 期限 | **每半年考察 1 次**；须**满 1 年**方可进入阶段三 |
| 材料 | 考察记录（每次一条） |
| 规则 | `PERIODIC_RULE(interval=180天)` + `INTERVAL_RULE(days=365)` |
| 说明 | 方法：吸收入党积极分子听党课、参加党内有关活动、分配一定的社会工作、集中培训等。目的：使其懂得党的性质、纲领、宗旨、组织原则、纪律、党员的义务和权利，端正入党动机。**注意**：工作、学习单位（居住地）发生变动，应及时报告原单位（居住地）党组织，原单位应及时转交材料，接收单位应认真审查、做好接续培养，**培养教育时间可连续计算** |

## 阶段三：发展对象的确定和考察

### STEP_07 确定发展对象

| 项 | 内容 |
|---|---|
| 办理角色 | 支部委员会 |
| 期限 | **经过 1 年以上培养教育和考察** → `INTERVAL_RULE(基准=STEP_03, days=365)` |
| 材料 | 支委会会议记录、听取意见记录 |
| 规则 | `INTERVAL_RULE` + `QUALIFICATION_RULE`：基本具备党员条件 |
| 说明 | 要求：听取党小组、培养联系人、党员和群众意见。确定：支部委员会讨论同意，确定发展对象人选 |

### STEP_08 报上级党委备案

| 项 | 内容 |
|---|---|
| 办理角色 | 上级党委 |
| 期限 | — |
| 材料 | 备案表 |
| 规则 | `MATERIAL_REQUIRED_RULE` |
| 说明 | 要求：认真审查，提出意见。注意：同意后列为发展对象 |

### STEP_09 确定入党介绍人

| 项 | 内容 |
|---|---|
| 办理角色 | 支部委员会 / 培养联系人 |
| 期限 | — |
| 材料 | 入党介绍人登记表 |
| 规则 | `QUALIFICATION_RULE`：数量 **2 名正式党员**；一般由培养联系人担任，也可由党组织指定；**受留党察看处分、尚未恢复党员权利的党员，不能作入党介绍人** |
| 说明 | 要求：入党介绍人认真完成培养、教育任务 |

### STEP_10 进行政治审查

| 项 | 内容 |
|---|---|
| 办理角色 | 支部委员会 |
| 期限 | — |
| 材料 | **政治审查结论性材料** |
| 规则 | `QUALIFICATION_RULE`：未经政治审查或政治审查不合格的，**不能发展入党** |
| 说明 | **内容**：对党的理论和路线、方针、政策的态度；政治历史和在重大政治斗争中的表现；遵纪守法和遵守社会公德情况；直系亲属和与本人关系密切的主要社会关系的政治情况。**方法**：同本人谈话、查阅档案资料、找有关单位和人员了解情况以及必要的函调或外调。对流动人员中的发展对象还应征求户籍所在地和居住地基层党组织的意见。**要求**：政治审查必须严肃认真、实事求是，注重本人的一贯表现。审查情况形成结论性材料 |

### STEP_11 开展集中培训

| 项 | 内容 |
|---|---|
| 办理角色 | 基层党委 / 县级党委组织部门 |
| 期限 | **不少于 3 天（24 学时）** → `TRAINING_HOUR_RULE(days=3, hours=24)` |
| 材料 | 培训结业证明、培训签到表 |
| 规则 | `TRAINING_HOUR_RULE` |
| 说明 | **注意**：未经培训的，除个别特殊情况外，不能发展入党 |

## 阶段四：预备党员的接收

### STEP_12 支部委员会审查

| 项 | 内容 |
|---|---|
| 办理角色 | 支部委员会 |
| 期限 | — |
| 材料 | 审查意见、群众意见汇总 |
| 规则 | `MATERIAL_REQUIRED_RULE` |
| 说明 | 要求：征求党员和群众的意见；对发展对象进行严格审查；集体讨论是否合格 |

### STEP_13 上级党委预审

| 项 | 内容 |
|---|---|
| 办理角色 | 上级党委 |
| 期限 | — |
| 材料 | 预审意见 |
| 规则 | `QUALIFICATION_RULE`：**发展对象未来 3 个月内将离开工作、学习单位的，一般不办理接收预备党员手续** |
| 说明 | **方式**：审查发展对象条件、培养教育情况等；根据需要，听取执法执纪等部门意见。**要求**：审查结果书面通知党支部；向审查合格的发展对象发放《中国共产党入党志愿书》。**注意**：发展对象未来 3 个月内将离开工作、学习单位的，一般不办理接收预备党员手续 |

### STEP_14 填写入党志愿书

| 项 | 内容 |
|---|---|
| 办理角色 | 发展对象本人（入党介绍人指导） |
| 期限 | — |
| 材料 | 《中国共产党入党志愿书》 |
| 规则 | `MATERIAL_REQUIRED_RULE` |
| 说明 | 要求：在入党介绍人指导下，由本人按照要求如实填写 |

### STEP_15 支部大会讨论 ⭐投票

| 项 | 内容 |
|---|---|
| 办理角色 | 支部大会 |
| 期限 | — |
| 材料 | 支部大会决议、表决记录、会议记录 |
| 规则 | `VOTE_RULE` |
| 说明 | **程序**：(1) 发展对象汇报个人情况；(2) 入党介绍人介绍发展对象有关情况、表明意见；(3) 支部委员会报告审查情况；(4) 与会党员充分讨论、投票表决。**注意**：有表决权的到会人数**必须超过应到会有表决权人数的半数**，才能开会；**赞成人数超过应到会有表决权的正式党员的半数**，才能通过。讨论两个以上发展对象入党时，要逐个讨论和表决 |

### STEP_16 上级党委派人谈话

| 项 | 内容 |
|---|---|
| 办理角色 | 上级党委派员（党委委员或组织员） |
| 期限 | 党委审批前 |
| 材料 | 谈话记录（填入入党志愿书） |
| 规则 | `MATERIAL_REQUIRED_RULE` |
| 说明 | **目的**：作进一步了解，并帮助发展对象提高对党的认识。**要求**：谈话人应当将谈话情况和自己对发展对象能否入党的意见，如实填写在《中国共产党入党志愿书》上，并向党委汇报 |

### STEP_17 上级党委审批

| 项 | 内容 |
|---|---|
| 办理角色 | 上级党委 |
| 期限 | **3 个月内** → `DEADLINE_RULE(days=90)` |
| 材料 | 审批意见、党委会会议记录 |
| 规则 | `DEADLINE_RULE` |
| 说明 | **要求**：审批结果及时通知党支部。支部书记应当同本人谈话，并将审批结果通知本人。**注意**：**党员的党龄从预备期满转为正式党员之日算起** |

### STEP_18 再上一级党委组织部门备案

| 项 | 内容 |
|---|---|
| 办理角色 | 再上一级党委组织部门 |
| 期限 | — |
| 材料 | 备案表 |
| 规则 | `MATERIAL_REQUIRED_RULE` |
| 说明 | **目的**：掌握预备党员结构、分布、质量等情况，发现问题，及时解决 |

## 阶段五：预备党员的教育考察和转正

### STEP_19 编入党支部和党小组

| 项 | 内容 |
|---|---|
| 办理角色 | 支部委员会 |
| 期限 | — |
| 材料 | — |
| 规则 | — |
| 说明 | 要求：及时编入；继续进行教育和考察 |

### STEP_20 入党宣誓

| 项 | 内容 |
|---|---|
| 办理角色 | 基层党委 / 党支部（党总支） |
| 期限 | — |
| 材料 | 宣誓活动记录、照片 |
| 规则 | `MATERIAL_REQUIRED_RULE` |
| 说明 | **程序**：(1) 奏《国际歌》；(2) 党组织负责同志致辞；(3) 预备党员宣誓；(4) 参加宣誓的预备党员代表发言；(5) 党组织负责同志讲话、提出要求。**要求**：在**正式场合**举行；严肃认真；庄重简朴；严密紧凑 |

| 项 | 内容 |
|---|---|

| 期限 | **预备期 1 年** → `PERIODIC_RULE(interval=90天)` + `INTERVAL_RULE(days=365)` |
| 材料 | 考察记录（多次） |
| 规则 | `PERIODIC_RULE` + `INTERVAL_RULE` |
| 说明 | **方式**：参加党的组织生活、听本人汇报、个别谈心、集中培训、实践锻炼等。**时间**：预备期为 1 年 |

| 项 | 内容 |
|---|---|
| 办理角色 | 预备党员本人 |
| 期限 | **预备期满**，书面提出 |
| 材料 | 转正申请书 |
| 规则 | `INTERVAL_RULE(基准=STEP_20/21起点, days=365)` |
| 说明 | 要求：预备期满，**书面**提出申请 |

### STEP_23 支部大会讨论 ⭐投票 + 分支

| 项 | 内容 |
|---|---|
| 办理角色 | 支部大会 |
| 期限 | — |
| 材料 | 支部大会决议、表决记录 |
| 规则 | `VOTE_RULE` + `BRANCH_RULE` |
| 说明 | **准备**：党小组提出意见；党支部征求党员和群众的意见；支部委员会审查。**程序**：参照接收预备党员的程序。**结果（三出口）**：<br>① 认真履行党员义务、具备党员条件的 → **按期转为正式党员**<br>② 需要继续考察和教育的 → **可以延长 1 次预备期**，延长**不能少于半年**，**最长不超过 1 年**<br>③ 不履行党员义务、不具备党员条件的 → **取消预备党员资格** |

`1-4` 年度入党申请人名册(台账)、`2-7` 积极分子培训班学员名册(台账)、`4-8` 年度新发展党员名册(台账)。

> 前端在 25 步时间轴的每一步展示该步骤的材料清单，带「必备/选填/台账」标签、
> 出具方、下载空表/填写样例、填写说明，以及**该人是否已上传**。
> 齐备度统计只计**必备且非台账**的个人材料。

### 统一材料提交与本人步骤提交（V5）

- 材料上传统一通过 `/develop/applicant/{applicantId}/materials/{templateId}`，客户端只提交申请实例、模板和文件；人员、组织、步骤、材料类型、模板编码等归属字段全部由后端派生。
- `APPLICANT` 只能给**本人**上传 `submit_role=APPLICANT` 的材料；同组织的其他申请人也不能互相代传。
- `BRANCH`、`PARENT_ORG` 除模板出具方匹配外，还要同时满足管理角色/组织级别和数据范围；`TRAINER` 使用 `dev_applicant.trainer_ids` 的精确培养联系人关系授权。
- 未来步骤禁止提前上传；流程进行中可按原出具方补录历史材料；组织台账 `is_roster=1` 不走个人材料入口。
- STEP_06 等周期性步骤允许同模板保留多次提交历史；普通单次模板再次上传采用替换语义。
- STEP_01、STEP_14、STEP_22 仍由 APPLICANT 本人推进，但不授予通用 `develop:applicant:handle`。申请人使用专用 `/develop/applicant/{applicantId}/self-submit`；只有本人、当前步骤确属 APPLICANT 办理且本步骤本人必备材料齐备时才能推进。
- STEP_02、STEP_06、STEP_10 虽包含本人出具材料，但步骤办理人仍是党组织/培养联系人；申请人只能上传本人材料，不能借此推进这些组织办理步骤。
